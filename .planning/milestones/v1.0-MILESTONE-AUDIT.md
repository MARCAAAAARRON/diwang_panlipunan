## 4. End-to-End User Flows & Integration Verification

1. **Reader Discovery & Reading Journey:**
   - User visits `/` (Landing page) → selects "Tuklasin ang mga Paksa" → navigates to `/home` topic portal.
   - User selects a thematic topic (e.g., `/topics/karapatang-pantao`) → views topic overview and subtopics list.
   - User opens an article (e.g., `/topics/karapatang-pantao/extrajudicial-killings`) → reads article with reading time estimate, sticky editorial sidebar, and top 2.5px progress bar.
   - In-text citation anchors jump smoothly to reference entries in `#sanggunian`.
   - Reader triggers broadsheet print layout (`window.print()`) or copies deep link with toast confirmation.
   - Reader reviews 3 curated related subtopics at article footer.

2. **Full-Text Search Journey:**
   - Reader triggers `Cmd+K` or clicks search icon from header on any page.
   - Quick search modal performs live debounced bilingual queries against `/api/search`.
   - Reader can press Enter to navigate to full `/search?q=...` view with pagination, topic badges, and excerpt snippets.
   - Searches are anonymously recorded in the first-party analytics system.

3. **Civic Participation & Community Feedback:**
   - At the base of any subtopic article, reader selects "Oo" or "Hindi" on the binary feedback widget.
   - Vote is locked locally in `localStorage` to prevent duplicate submissions; optional qualitative explanation field expands.
   - Reader navigates to `/magmungkahi` (`/suggest`) to submit a new societal issue suggestion. Form validates via Zod and blocks bot spam via honeypot field.

4. **Editorial CMS & Administration:**
   - Admin accesses `/admin` → unauthenticated sessions redirected to `/admin/login`.
   - Admin logs in with Supabase Auth credentials.
   - Admin creates or edits a subtopic: live split-screen editor renders GFM Markdown, calculates WPM read time, and allows inline citation source management.
   - Admin uploads cover images directly to Supabase Storage with automatic URL assignment.

5. **Triage, Moderation & Internal Analytics:**
   - Admin accesses `/admin/feedback` to review reader satisfaction ratios and qualitative feedback comments per subtopic.
   - Admin accesses `/admin/suggestions` to triage reader proposals with status switches (Pending → In Review → Implemented → Dismissed).
   - Admin accesses `/admin/analytics` to view overall readership statistics, theme popularity distribution, most-read articles, and frequent search terms.
