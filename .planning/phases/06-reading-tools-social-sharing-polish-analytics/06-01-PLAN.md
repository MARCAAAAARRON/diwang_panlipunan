# Plan 06-01: Reading Depth Indicator & Broadsheet Print/PDF Layout

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Unvalidated Print Injection / Layout Tampering | V5.1.4 (Client-Side Rendering) | Print formatting strictly leverages CSS `@media print` rules without injecting unescaped HTML or external DOM scripts. |
| Excessive Scroll Event Listener Overhead | V11.1.1 (Performance & Resilience) | Scroll progress uses requestAnimationFrame throttling and passive event listeners on scroll. |
</threat_model>

<user_story>
**As a** student, researcher, or educator,  
**I want** to track my reading progress with an unobtrusive progress indicator and print or export clean paper/PDF copies of articles,  
**so that** I can maintain reading focus and produce physical or digital study handouts for classrooms and civic discussions.
</user_story>

  <name>Build Minimalist Reading Depth Progress Bar [READ-03, D-01]</name>
  <read_first>
    - .planning/phases/06-reading-tools-social-sharing-polish-analytics/06-CONTEXT.md
    - src/app/topics/[topic]/[subtopic]/page.tsx

  <action>
    1. Create `src/components/reading/reading-progress-bar.tsx`:
       - Client Component tracking scroll position relative to the article content element (`#aralin`).
       - Calculates percentage: `(window.scrollY - articleTop) / (articleHeight - window.innerHeight) * 100`.
       - Renders a fixed 2.5px bar at the top of the viewport (`fixed top-0 left-0 right-0 h-[2.5px] z-50 pointer-events-none`).
       - Accepts `colorToken?: string` to dynamically tint the bar with the active topic colorway, or defaults to `var(--color-primary)`.
       - Uses `requestAnimationFrame` for 60fps performance and passive event listeners.
    2. Mount `<ReadingProgressBar />` in `src/app/topics/[topic]/[subtopic]/page.tsx`.
  </action>
  <acceptance_criteria>
    - 2.5px progress bar fixed at the top edge of the viewport
    - Smoothly transitions from 0% to 100% as the reader scrolls through the article
    - Adopts the active societal topic accent color
    - Zero intrusive floating pillboxes or widgets
  </acceptance_criteria>
  <verify>
    Verify component compiles without type errors via `npm run build`.
  </verify>
  <done>
    Reading progress indicator is live on all subtopic reading pages.
  </done>
