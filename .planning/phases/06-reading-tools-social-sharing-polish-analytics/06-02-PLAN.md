# Plan 06-02: Related Subtopics Recommendation Engine & Social Sharing

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Open Redirect / Unsafe Share Intent URLs | V5.1.5 (URL Redirection) | Social sharing links use strict sanitized URL encoding with known social share base URLs (facebook.com, twitter.com) without executing arbitrary scripts. |
| Insecure Clipboard Manipulation | V5.1.3 (Browser API Safety) | Clipboard copy uses `navigator.clipboard.writeText(window.location.href)` guarded by HTTPS / window focus check and fallback input element. |
| Malicious Metadata Injection | V5.3.1 (Output Encoding) | Open Graph meta tags sanitize article titles and summaries using Next.js metadata API to prevent meta injection. |
</threat_model>

<user_story>
**As a** learner or civic advocate,  
**I want** to discover intersecting societal analyses at the end of each aralin and easily share articles to social media or copy deep links,  
**so that** I can explore systemic connections between Philippine issues and disseminate credible knowledge across civic networks.
</user_story>
