# Plan 05-03: Admin Feedback Analytics & Topic Suggestion Triage Dashboards

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Unauthorized Feedback & Suggestion Access | V4.1.1 (Access Control) | Feedback and suggestion triage routes are guarded by Next.js middleware and Supabase RLS policies ensuring only `role === 'admin'` profiles can query or modify triage records. |
| Insecure Status Manipulation | V5.1.5 (Data Validation) | Suggestion status transitions are strictly validated against allowed enum values: `'pending'`, `'in_review'`, `'implemented'`, `'dismissed'`. |
| XSS via Public User Submissions in CMS | V5.3.1 (Output Encoding) | Reader comments and suggested topic notes are HTML-encoded during rendering in the admin dashboard. |
</threat_model>

<user_story>
**As an** administrator or editor on the editorial board,  
**I want** to analyze reader satisfaction metrics, review user comments, and triage community-suggested topics through an organized review pipeline,  
**so that** we can continuously improve pedagogical clarity and address topics demanded by Filipino learners.
</user_story>
