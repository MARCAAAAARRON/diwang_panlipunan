# Plan 04-03: Subtopic Article Management & Split-Screen Live Markdown Editor

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Malicious Markdown Injection / XSS | V5.1.3 (Input Sanitation) | Markdown preview uses the safe `MarkdownRenderer` with sanitized HTML rendering. Server actions strictly strip executable script payloads before database storage. |
| Insecure Article Deletion / State Overwrite | V4.1.2 (Access Control) | Delete and update operations require confirmed admin session and enforce RLS policies. Deletions require explicit client confirmation dialog. |
| Broken Content Relationships | V5.1.5 (Data Validation) | `topic_id` foreign keys and slugs are validated against regex `^[a-z0-9-]+$` and verified against existing topics before article insertion. |
</threat_model>

<user_story>
**As an** editor or content curator,  
**I want** to write and edit long-form subtopic articles using a split-screen Markdown editor with live broadsheet preview and auto-calculated reading times,  
**so that** I can craft high-quality educational analyses with immediate visual feedback.
</user_story>
