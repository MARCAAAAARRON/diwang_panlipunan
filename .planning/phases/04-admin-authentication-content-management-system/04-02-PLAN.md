# Plan 04-02: Thematic Topics Management & Asset Storage Upload

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Malicious File Upload (Web Shells / Executables) | V12.1.1 (File Upload Verification) | File upload component strictly enforces MIME type validation (allowing only `image/jpeg`, `image/png`, `image/webp`), enforces 5MB file size limit, and sanitizes file names. |
| Unauthorized Mutation of Core Themes | V4.1.2 (Access Control) | Topic update server actions strictly authenticate session and verify admin role before performing database updates via RLS-guarded Supabase client. |
| Insecure External Media Injections | V5.1.4 (Input Sanitation) | External media URLs are validated to require `http://` or `https://` schemas and point to valid image hosts. |
</threat_model>

<user_story>
**As an** administrator of Diwang Panlipunan,  
**I want** to manage the 7 societal themes, update their descriptions, colors, and banner assets,  
**so that** the thematic directory remains accurate, culturally resonant, and visually coherent.
</user_story>

  <read_first>

    - src/lib/supabase/client.ts
    - docs/DESIGN.md §2 (Border & surface styling)
  </read_first>
  <action>
    Create `src/components/admin/image-uploader.tsx`:
    1. Client Component with `"use client"`.
    2. Accepts `value: string`, `onChange: (url: string) => void`, `bucketName?: string` (default: `"topic-assets"`).
    3. Tabbed or dual-mode input:
       - Mode A: Drag-and-drop file upload zone.
         - Validates file type (`image/jpeg`, `image/png`, `image/webp`) and size (max 5MB).
         - Uploads to Supabase Storage bucket using `supabase.storage.from(bucket).upload(...)`.
         - Obtains public URL via `getPublicUrl(...)` and invokes `onChange(publicUrl)`.
       - Mode B: Direct Image URL input for external editorial assets with instant validation.
    4. Displays live thumbnail preview with a "Tanggalin ang Larawan" (Remove) action.
    5. Fallback simulation: If Supabase Storage environment is unavailable or in offline mode, persists the image locally as data URI or fallback URL without crashing.
  </action>
  <acceptance_criteria>
    - Supports both file drop/select and direct URL inputs
    - Validates image types and size limits
    - Displays thumbnail preview of selected image
    - Handles offline/missing storage gracefully
  </acceptance_criteria>
  <verify>
    Verify component compiles cleanly via `npm run build`.
  </verify>
  <done>
    Dual-mode image uploader is ready for CMS forms.
  </done>
