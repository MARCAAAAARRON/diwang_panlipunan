# Plan 02-02: Content Drawer (`Nilalaman`) & Nested Topic Navigation

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Open Redirect / URL Poisoning in Navigation Links | V5.1.3 (Input Sanitation) | All route links inside the Content Drawer are constructed strictly from validated internal topic and subtopic slugs matching regex `^[a-z0-9-]+$`. No arbitrary user input or unsanitized external query params are reflected in href attributes. |
| Denial of Service via Unbounded Drawer Re-renders | V11.1.1 (Business Logic) | Drawer state uses memoized context and state handlers. Body scroll lock cleanly cleans up listeners on component unmount to prevent lingering window event listeners or locked scroll state. |
| Inaccessible Focus Traps | V14.4.1 (UI Architecture) | Keyboard trap properly cycles Tab / Shift+Tab within the drawer container while open and releases focus back to the triggering hamburger button upon close via `Escape` or button click. |
</threat_model>

<user_story>
**As a** reader of Diwang Panlipunan,  
**I want** to open the "Nilalaman" content drawer from anywhere on the platform, browse all 7 societal themes and their nested subtopics in an accordion, and jump directly to any article,  
**so that** I have full visibility into the publication's scope and my current location within the learning curriculum.
</user_story>
