# Plan 02-03: Broadsheet Landing Page & Static Informational Pages

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Open URL Redirection in Route Aliases | V5.1.4 (Input Sanitation) | URL rewrites in `next.config.mjs` are strictly configured internal destination rewrites without wildcard user input interpolation or external host forwarding. |
| Insecure Image Delivery / Mixed Content | V14.4.1 (Content Security) | Use Next.js `<Image>` component with local optimized assets or strictly HTTPS configured image loaders. Hero images are bundled in `public/` or safely served with explicit width, height, and alt attributes. |
| Malicious Content Injection in Static Pages | V5.3.1 (Output Encoding) | All educational and institutional copy is statically compiled in TypeScript React Server Components, eliminating dynamic injection vulnerabilities. |
</threat_model>

<user_story>
**As a** student, educator, or Filipino citizen,  
**I want** to visit the public Landing page, read about the platform's educational mission, access the contact channels, and view privacy policies,  
**so that** I understand the purpose, rigor, and trustworthiness of Diwang Panlipunan before diving into societal research.
</user_story>
