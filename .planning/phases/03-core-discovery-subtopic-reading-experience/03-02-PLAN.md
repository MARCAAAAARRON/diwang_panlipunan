# Plan 03-02: Subtopic Article Reader & Editorial Layout

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Stored / DOM-based Cross-Site Scripting (XSS) in Markdown | V5.1.3 (Input Sanitation) | `react-markdown` is configured with strict safe rendering defaults. Disallow arbitrary HTML script injection and validate any parsed images or links. |
| Insecure External Link Hijacking | V14.2.1 (Component Isolation) | Custom link components in the Markdown renderer strictly enforce `target="_blank"` and `rel="noopener noreferrer"` on all external URLs. |
| Client-Side Layout Shift & CSS Injection | V14.4.1 (UI Architecture) | `--topic-color` is set strictly from validated CSS theme token names (e.g. `var(--topic-kapaligiran)`). Raw arbitrary CSS injections from user inputs are prevented. |
</threat_model>

<user_story>
**As a** reader of Diwang Panlipunan,  
**I want** to read long-form subtopic articles styled with editorial broadsheet typography, topic banner colors, pullquotes, data callouts, and desktop navigation sidebars,  
**so that** I can engage in deep, distraction-free study of Philippine contemporary issues.
</user_story>
