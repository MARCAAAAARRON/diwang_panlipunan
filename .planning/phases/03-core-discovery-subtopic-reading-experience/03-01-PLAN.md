# Plan 03-01: Topics Thematic Catalog & Individual Topic Hubs

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| SQL / Query Parameter Injection via Slugs | V5.1.3 (Input Sanitation) | Topic and subtopic slugs received from route params are sanitized and strictly validated against regex `^[a-z0-9-]+$`. Parameterized Supabase queries are used exclusively. |
| Server-Side Resource Exhaustion / Uncached Fetching | V11.1.1 (Business Logic) | Server Components utilize Next.js cache / revalidation semantics and resilient local in-memory fallback models, preventing repeated database connection pool exhaustion. |
| Unauthorized Access to Draft Topics | V4.1.1 (Access Control) | Public directory and topic hub endpoints filter exclusively for `status = 'published'` unless a verified admin session is present. |
</threat_model>

<user_story>
**As a** student or researcher,  
**I want** to browse all 7 societal themes, view article counts and publication statuses, and explore individual topic hubs,  
**so that** I can easily find structured curricular areas that match my learning interests.
</user_story>

    Create `src/lib/content-service.ts`:
    1. Implement helper functions for retrieving published content:
       - `getAllTopics()`: Fetches all 7 topics ordered by `order_index`, annotated with published subtopic counts.
       - `getTopicBySlug(slug: string)`: Fetches a single topic with its subtopics and citations.

       - `getAdjacentSubtopics(topicSlug: string, subtopicSlug: string)`: Retrieves the previous and next subtopics in curriculum order.
    2. Resilient Database & Seed Hybrid (D-11):

       - If Supabase environment variables are missing or connection fails/times out, seamlessly returns the embedded canonical seed data covering all 7 topics, 21 subtopics, and academic citations from `00003_seed_data.sql`.
       - Ensures zero runtime crashes or blank screens in offline or local test environments.
