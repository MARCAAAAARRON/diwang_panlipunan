# Plan 03-03: Citations Component & Smooth In-Text Citation Anchors

<threat_model>
## Security Threat Model (ASVS Level 1)

| Threat | ASVS Requirement | Mitigation Strategy |
|---|---|---|
| Tabnabbing / Reverse Tabnabbing via Citations | V14.2.1 (Component Isolation) | Every citation link pointing to an external source strictly enforces `rel="noopener noreferrer"` and `target="_blank"` attributes. |
| Malicious URL Schemes in Citation References | V5.1.3 (Input Sanitation) | Citation URLs are strictly validated to allow only `http://` and `https://` protocols, neutralizing `javascript:` or `data:` URL execution vulnerabilities. |
| DOM Anchor Script Injection | V5.3.1 (Output Encoding) | Citation anchor IDs use strict numeric format `#sanggunian-[n]` and avoid unsanitized DOM string injection. |
</threat_model>

<user_story>
**As a** student or academic researcher,  
**I want** to see verified citation sources for every factual assertion in the article and click in-text references to jump smoothly to the bibliography,  
**so that** I can verify primary data sources, assess evidentiary credibility, and consult original publications.
</user_story>

         ```javascript
         const target = document.getElementById(`sanggunian-${refNumber}`);
         if (target) {
           target.scrollIntoView({ behavior: 'smooth' });
           target.classList.add('citation-highlight');
           setTimeout(() => target.classList.remove('citation-highlight'), 2000);
         }
         ```
       - Renders with accessible `aria-label={`Pumunta sa sanggunian bilang ${refNumber}`}`.
       - Tooltip on hover displaying source author or title.
    2. Update `src/components/reading/markdown-renderer.tsx` to detect citation notation (`[^n]` or `[n]`) and replace with `<CitationAnchor />`.
    3. In `src/app/globals.css`, add subtle highlight keyframe animation:
       ```css
       @keyframes citationFlash {
         0% { background-color: var(--color-highlight); }
         100% { background-color: transparent; }
       }
       .citation-highlight {
         animation: citationFlash 2s ease-out;
         border-radius: 4px;
       }
       ```
    4. Integrate citations list into `src/app/topics/[topic]/[subtopic]/page.tsx` beneath the article body.
